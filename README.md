# SafeBreach Attack Studio

**SafeBreach Attack Studio** is a Visual Studio Code extension that brings SafeBreach custom attack
development into your IDE — an industry-standard developer experience for building, debugging, and
managing SafeBreach custom attacks as an alternative to the web-based Breach Studio.

> **This repository is the public home page for the extension.** It hosts install instructions and
> issue tracking only. The extension's source is maintained privately by SafeBreach; this page exists so
> the published extension has a stable, resolvable project link.

## Install

The extension is published to **both** major VS Code extension registries, so you can install it from
whichever your editor and environment support:

- **Visual Studio Marketplace** (VS Code):
  <https://marketplace.visualstudio.com/items?itemName=SafeBreach-Validate.safebreach-attack-studio>
  ```
  ext install SafeBreach-Validate.safebreach-attack-studio
  ```
- **Open VSX Registry** (VSCodium, Cursor, Gitpod, Eclipse Theia, and other Open VSX–based editors, and
  environments that proxy Open VSX through an artifact manager such as JFrog Artifactory):
  <https://open-vsx.org/extension/SafeBreach-Validate/safebreach-attack-studio>

Extension identifier: **`SafeBreach-Validate.safebreach-attack-studio`**

## Getting started

After installing, configure your SafeBreach console connection (Base URL, API Token, Account ID) in the
extension settings, then use the SafeBreach views and commands to create, debug, and manage attacks.
